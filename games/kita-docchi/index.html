お客さん、北はどっちです？

曇った窓のタクシーが曲がったあと、目的地はどっち？

どんなゲーム？

窓が曇った夜のタクシーに乗ると、何回か曲がったあとで、運転手さんが「このあと北に進めば目的地です」と言います。曲がった向きを頭の中でたどって、その方角にあたる道をタップするゲームです。正しい道を選べれば正解です。

10問で方向感覚を診断する「診断モード」と、間違えるまで続く「エンドレスモード」があります。問題が進むと、南東・北東のような斜めの方角も出てきます。

遊び方

  1. タイトル画面で「10問 診断モード」か「エンドレス」を選びます。
  2. 乗る前に、羅針盤（東西南北）と「いま車は◯向き」が数秒だけ出ます。向きを覚えて「乗る」を押すと出発します。押さなくても、数秒で出発します。
  3. タクシーに乗ると、羅針盤は消えます。窓が曇っていて外はぼんやりとしか見えません。その間に、車は何回か曲がります。
  4. 停車すると、交差点を真上から見た画面になり、「このあと◯に進めば目的地です」と言われます。車は画面の上向きです。進む道をタップします。パソコンではクリックします。
  5. 正解・不正解と、走ってきた道を上から見た図が出ます。「つぎの問題へ」で次に進みます。

ルール

  • 車が曲がるのは、いつも右か左に90度です。斜めになるのは、目的地の方角だけです。
  • 目的地の方角は、道が4本の画面では東西南北のどれか。道が8本の画面では、南東・北東・南西・北西も出ます。
  • 制限時間はありません。走っている間は操作できず、停車してから、じっくり考えて答えられます。
  • 診断モードは全10問です。1〜4問目は曲がる回数が3〜4回で道は4本。5〜7問目は5〜6回で道は4本。8〜10問目は6〜7回で道が8本になり、斜めの方角が答えになる問題が約6割まじります。
  • 診断モードは、正解数で称号が決まります。9〜10問が「人間コンパス」、7〜8問が「方位センサー持ち」、5〜6問が「ふつうの人」、3〜4問が「地図アプリが命」、0〜2問が「迷子の常連」です。
  • エンドレスモードは、1問でも間違えると終わりです。点数は連続で正解した数です。曲がる回数は3回から始まり、2問ごとに1回ずつ増えます（最大12回）。速さは毎問6%ずつ上がります（最大2.5倍）。6問目からは道が8本になり、斜めの方角の割合もだんだん増えます。
  • エンドレスは、連続正解が20問以上で「人間コンパス」、15問以上で「方位センサー持ち」、10問以上で「ふつうの人」、5問以上で「地図アプリが命」、それ未満は「迷子の常連」です。ベスト記録は、遊んでいるブラウザに残ります。

うまくなるコツ

  • 向きは「北・東・南・西」の4つを順番に数えます。右に曲がると北→東→南→西→北の順に、左に曲がると逆の順に回ります。曲がるたびに、心の中で「右、東」「左、北」のように言うと、数え間違いが減ります。
  • 曲がるときは、車内の景色が少し傾きます。右か左かを思い出す手がかりになります。
  • ウインカーのような「カチカチ」という音が、曲がる前後に鳴ります。曲がった回数を数えるのに役立ちますが、右か左かは音では分かりません。
  • 答えるときは、最後に停車した向きから考えます。交差点では車が上向きなので、停車した向きが東なら、右が南、左が北、真後ろが西です。
  • 斜めの方角は、2つの方角のあいだです。南東は、南と東のあいだにあたります。道が8本の画面では、上から右まわりに45度ずつ並んでいます。
  • 間違えたときは、答え合わせの図を見直します。「はじめ◯向き ／ 右 → 左 → … ／ 停車時◯向き」と書いてあるので、どこで数え間違えたかが分かります。

見どころ

  • 舞台は夜の街です。ビルの窓の明かりや街灯、ネオンが、曇りガラスの向こうでにじんで見えます。
  • 答え合わせでは、走ってきた道が上から描かれます。出発した場所、停車した場所、正解の方角、あなたが選んだ方角が、一枚の図で分かります。
  • 問題は毎回ランダムに作られます。道の形も、街の景色も、遊ぶたびに変わります。
