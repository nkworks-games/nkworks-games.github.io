ニッポン真っ二つ

お題がちょうど半分になるように日本を切る

▶ ブラウザで遊ぶ（無料）インストールなし。リンクを開くとすぐ始まります。
  • 遊べる所スマホ（縦画面）・パソコン
  • 1回の長さ1回 約1〜2分（5問）
  • 公開日2026年10月3日
  • 料金無料（広告あり）

どんなゲーム？

人口、面積、神社の数など、出されたお題の数が左右でちょうど半分になるように、日本地図をまっすぐな線1本で切るゲームです。切ると両側の割合が出て、ズレが小さいほど高い点になります。「北海道だけで約2割」のような意外な偏りがわかるので、点数とあわせて答え合わせも楽しめます。

遊び方

  1. タイトル画面で「スタート！」を押します（新しいお題だけで遊ぶ「NEW」や、条件を満たすと開く「お題を選ぶ」もあります）。
  2. 画面の上に出るお題（例：歯医者さんの数）を見て、どこで切れば半分になるか考えます。
  3. 地図の上を指でスワイプして線を引き、指をはなすと切れます。線の向きは自由で、まっすぐ1本です。
  4. 細かくねらいたいときは、スマホは2本指、パソコンはマウスのホイールで地図を拡大できます。パソコンではマウスのドラッグで線を引きます。
  5. 切ると両側の割合とズレ、点数が出ます。「次の問題」で進み、5問で結果発表です。

ルール

  • 1回のプレイはランダムに選ばれた5問で、1問の制限時間は15秒です。時間切れや、線が日本にかからなかったときは0点です。
  • ちょうど50%ずつで100点、ズレが1%ふえるごとに5点減ります。5問の合計（最高500点）で競います。
  • 合計点で「真っ二つ名人」から「かけだし」までのランクがつきます。
  • お題を50種遊ぶと「お題を選ぶ」が開き、好きなお題を5つ選んで遊べます（この回はベストスコアには入りません）。

うまくなるコツ

  • お題ごとに日本のどこに数が集まっているかを考えるのが先です。北海道や東京が大きくかたよるお題が多くあります。
  • 線は横だけでなく、ななめや縦にも引けます。かたよっている地域を片側にまとめる向きを探すと半分にしやすくなります。
  • 県境の近くをねらうときは、拡大してから線を引くとズレを小さくできます。
  • 切った後に出る「ここで半分！」の線とひとことヒントを見ておくと、同じお題が来たときに役立ちます。
  • 作者がいちばん苦戦したお題は「サトウキビの生産量」です。作っているのがほとんど沖縄と鹿児島なので、南のほうで細かく切ることになります。ズームを使うのがおすすめです。

見どころ

  • お題は全112種。特産品、消費、お店、自然・乗物、人・文化のジャンルがあり、それぞれに出典がついています。
  • 第2弾で増えた62種だけで遊べる「NEW」モードがあります。
  • まだ出ていないお題から出題されるので、同じお題がすぐにくり返されにくくなっています。
  • 結果は「Xでシェア」から、点数・ランク・平均ズレをつけて投稿できます。

作ったときの話

このゲームは、急にポッと思いつきました。

最初はお題20個で公開しました。Xに投稿したら思ったより反応がよかったので、お題を増やすことにしました。

増やすときに、同じお題が何回も続かないようにして、全部のお題を遊んだ人は好きなお題を5つ選んで遊べるようにしました。ミスした時の言い方が煽るような口調になっていたところも、煽らない言い方に直しました。

そのあとの第2弾で、お題を112個まで増やし、新しいお題だけで遊べる「NEW」モードと、細かく切りたい時のズームを足しました。

作者のひとこと

日本地図を、人口や面積などのお題がちょうど半分になる所で切ったらおもしろいと思って作りました。線は角度自由の1本だけで、見た目はポップなクイズ番組風にしています。公開後にXで好評だったので、お題を追加する更新をして、今は112種あります。同じお題が続かないようにしたことと、ミスしたときの文言を煽らない言い回しにしたことも、更新で気をつけた所です。細かい所を切りやすいように、拡大もできるようにしました。
