国民度チェック

日の丸を一筆で描いて、国民度を測る

▶ ブラウザで遊ぶ（無料）インストールなし。リンクを開くとすぐ始まります。

どんなゲーム？

白い旗に赤い丸を一筆で描いて、日の丸を完成させるゲームです。描いた丸が本物の日の丸とどれだけ重なるかを「国民度」として％で出し、その数字によって4つのエンディングのどれかになります。飛行機で日本を出ていく結末から、家が開いて大勢に拍手され、ニュースや街の電光掲示板にまで出る結末まであります。

遊び方

  1. タイトル画面で「描きはじめる」を押します。
  2. 白い旗（縦2：横3）に、赤い丸を指でなぞって一筆で描きます。パソコンではマウスのドラッグで描きます。
  3. 指をはなすと提出です。描いた線の内側が赤く塗られ、本物の日の丸の位置が点線で出ます。描き直しはできません。
  4. 国民度が％で出たら「エンディングへ」を押します。エンディングのあとの結果画面で、本物との重なり方とひとことアドバイスを確認できます。

ルール

  • 国民度は、描いた赤と本物の日の丸の「重なった面積 ÷ どちらかに入っている面積」です。ぴったり同じなら100%になります。
  • 本物の日の丸は、直径が旗の縦の3/5で、旗のど真ん中にあります。
  • 国民度が49%以下・50〜74%・75〜89%・90%以上で、4つのエンディングに分かれます。
  • 見たエンディングは「エンディング図鑑」に残り、あとから何度でも見られます。
  • 短すぎる線は描きミスとして数えず、もう一度描けます。

うまくなるコツ

  • 丸の直径は旗の縦の3/5で、半分より少し大きめです。小さく描きがちなので、思ったより大きく描くのがコツです。
  • 描く前に旗のまん中を目で決めておくと、位置のズレが減ります。
  • 線の真ん中が丸のふちになります。ゆっくり同じ速さで回すと、形がいびつになりにくくなります。
  • 結果画面の「ひとことアドバイス」（大きすぎ・右にずれ・形がいびつ など）を見て、次の1回で直しましょう。

見どころ

  • 4つのエンディングは、どれも絵が動く短いアニメです。飛行機で日本を出ていく、家で国旗を描く練習の日々、町内会で「町内国旗名人」として表彰、そして国民的英雄の4つがあります。
  • 国民度が90%以上のエンディングだけは3Dです。家が急に開いて大勢の人に囲まれ、カメラが空へ上がって街へ飛ぶと、ニュースにもなり、夜の街の電光掲示板があなたでいっぱいになります。
  • エンディングには、あなたが描いた日の丸がそのまま出てきます。空港に置いていかれたり、表彰式に飾られたり、テレビに映ったりします。
  • 結果は「Xでシェア」から、国民度とエンディング名をつけて投稿できます。

作者のひとこと

白い旗に丸を1つ描くだけで、どれだけ本物の日の丸に近いかを「国民度」として測ったらおもしろいと思って作りました。丸はきれいな円を置くのではなく、指で一筆描きにしています。ガタガタになってしまうのも楽しさのうちです。エンディングは一致度ごとに4つあり、いちばん上の結末は、家が開いて大勢に拍手され、ニュースや電光掲示板にまで出る大げさなものにしました。
