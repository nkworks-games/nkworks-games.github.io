鮭、のぼります。

河口から産卵場所まで、川をのぼりきれ。滝もクマも丸太も、ぜんぶこえて。

どんなゲーム？

鮭になって、生まれた川の産卵場所までのぼるタイムアタックです。前へは自動で泳ぐので、あやつるのは左右とジャンプだけ。ジャンプは長押しでタメて、はなすと跳びます。タメが長いほど高く跳べるので、滝の高さに合わせてタメる長さを変えるのがポイントです。

コースは河口から中流、紅葉の上流をぬけて産卵場所までの約1300m。滝・岩・クマ・急流のほかに、上流から流れてくる丸太、中州で左右に分かれる分かれ道、6段続く段々の滝があります。ミスしてもゲームオーバーにはならず、滝の下まで流し戻されるだけ。そのぶんタイムが遅くなります。自分のベストの走りは半透明の「ゴースト」になって、次から一緒に泳ぎます。

遊び方

  1. 「スタート」を押すと、3・2・1 のあとに泳ぎ始めます。
  2. スマホは画面を左右にドラッグ、パソコンは ← → キーで左右に泳ぎます。
  3. 右下のジャンプボタン（パソコンはスペースキー）を長押しでタメて、はなすとジャンプ。ゲージの「滝」の線までタメると、次の滝をちょうどこえられる高さになります。
  4. 左手で跳びたい人は、タイトル画面か一時停止の画面の「ジャンプボタン：右（タップで左に）」を押すと、ジャンプボタンを左下に移せます。
  5. 右上の II ボタンで一時停止できます。「最初からやり直す」「ホームにもどる」もここから選べます。
  6. 産卵場所の旗の下を通ったらゴール。タイムと称号が出ます。

ルール

  • 滝をこえられないと、滝の下まで流し戻されます。クマにはたかれた時も同じです。
  • 岩や丸太にぶつかると「ゴツン」で減速します。低い岩と丸太は跳び越えられます。
  • 滝をぎりぎりの高さでこえると「ジャスト！」で少しのあいだ加速します。続けて決めるとコンボになり、加速が強くなります。
  • 青く光る矢印の帯（追い流れ）に乗るか、水の輪をくぐると加速します。
  • 急流の白い流れでは押し戻されます。白くない「すき間」はふつうに泳げます。
  • クマの前の赤い範囲は、クマの手がとどく所です。手をふり下ろした瞬間にその中にいると、はたかれます。
  • タイムで称号が決まります。1分35秒未満で「伝説の鮭」です。

うまくなるコツ

  • 滝は、早く跳びすぎると落ちてくる途中でぶつかります。滝の近くで、ゲージが線に届いたところではなすのが確実です。
  • タメている間は泳ぐのが少し遅くなります。タメすぎると、そのぶんタイムが遅れます。
  • 中州の分かれ道は、左が速い道（追い流れあり。そのかわり丸太や岩が多い）、右が安全な道です。慣れてきたら左に挑戦してみてください。
  • 段々の滝は小さいジャンプで十分です。リズムよくジャストを続けると、どんどん速くなります。
  • クマは鮭の横に立とうとついてきます。手を上げて「！」が出たら、ふり下ろしが終わるのを待ってから跳びましょう。

作っていて変えたところ

最初の版は、川をまっすぐ泳いで滝を跳ぶだけでした。遊んでみると「もっと疾走感がほしい」「まっすぐ泳ぐだけの所が多い」と感じたので、泳ぐ速さを上げて、カメラを鮭の近くの低い位置に下げ、速いほど視野が広がるようにしました。コースにも追い流れや水の輪、流れてくる丸太、分かれ道、段々の滝を足して、約1000mから約1300mにのばしています。

もうひとつ困ったのが、ジャンプに失敗して滝の段差にぶつかったあと、ゲージの線までタメて跳んでも、また失敗して流されてしまうことでした。止まった状態から跳ぶと、ほぼ真上に跳ぶだけで滝まで届かなかったのが原因です。今は、上がっている途中で滝にぶつかっても、そのまま上がればふちに届く高さなら、滝にそってのぼれるようにしています。クマも最初はどこまで近づくと危ないのかわからなかったので、手がとどく範囲を赤く表示しました。
