そしてダルマは立ち上がった

美脚の生えたダルマで子供にタッチ

どんなゲーム？

転がっていたダルマに、長くてきれいな脚が生えて立ち上がります。夕暮れの日本家屋の廊下を玄関へ歩いていく子供を追いかけ、外へ出られる前にタッチするのが目的です。子供が振り向きそうになったら、長い脚を左右の壁に突っ張って隠れます。タッチまでのタイムを競う、ホラー風のバカゲーです。

遊び方

  1. 画面をタップするとスタート。ダルマに脚が生えて立ち上がります。
  2. 画面の左半分をタップすると左脚、右半分をタップすると右脚が出ます。左右を交互に、テンポよくタップして廊下を走ります。
  3. 子供の頭の上に「！」が出たら、左右を同時に長押しします。ダルマがジャンプして、脚を左右の壁に突っ張って止まります。
  4. 子供が前を向くまで指を離さずに待ち、前を向いたら離してまた走ります。
  5. 子供が玄関に着く前に追いつけば、タッチしてクリアです。
  6. パソコンでは ← → キー（A・D や F・J でも可）で左右の脚、スペースキーの長押しで突っ張ります。マウスだけなら左右クリックと「突っ張る」ボタンの長押しで遊べます。

ルール

  • 1回勝負です。廊下は1本、子供は1人です。
  • 子供が振り向いた時に壁に突っ張っていないと、見つかって即アウトです（「そしてダルマは見つかった。」）。
  • 子供が玄関に着いてしまっても失敗です（「そして子供は出かけていった。」）。
  • 壁に突っ張っていられるのは数秒だけです。長く続けるとすべって落ちてしまいます。
  • 記録はタッチまでのタイムです。8.3秒以内でSランク「神速の美脚」、そこからA「忍びの美脚」、B「なかなかの美脚」、C「千鳥足のダルマ」、D「生まれたての小鹿」になります。

うまくなるコツ

  • 連打しすぎると脚が空回りしたり、もつれたりして進みません。少し間をあけた一定のテンポで交互に押すほうが速く走れます。
  • 同じ側の脚を続けて出すと、ケンケンになって勢いが落ちます。
  • 走っていると左右にぶれていきます。壁に寄ってきたら、反対側の脚を多めに出してまん中へ戻りましょう。壁にぶつかるとよろけます。
  • 子供に近づきすぎたり、近くで壁にぶつかって音を立てたりすると「！」が出ます。
  • 子供が前を向き直った直後は、しばらく振り向きません。「今のうちに タッチ！」と出たら一気に詰めましょう。

見どころ

  • ダルマの後ろから見る縦画面の3Dで、夕暮れの日本家屋の廊下が舞台です。
  • タッチされた子供は、石のように固まって全身が灰色になります。
  • 結果画面では、タイムとランクのほかに「！」が出た回数と、壁にぶつかった回数も表示されます。
  • 失敗した時は、次に役立つコツが表示されます。
  • 自己ベストを保存し、タイムとランクをXでシェアできます。

作者のひとこと

出発点は「ダルマに超きれいで長い美脚が生えたら」という思いつきでした。一度は、美脚でランウェイを歩くゲームにしようと決めましたが、それはやめて、廊下で子供を追いかける形にしました。見つかりそうな時に、長い脚を突っ張り棒のように左右の壁に張って体を支えるのがポイントです。走る操作は、わざと扱いにくくしています。夕暮れの日本家屋を舞台にした、ホラー風のバカゲーです。
