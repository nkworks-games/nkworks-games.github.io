桃太郎ライド

時速190kmで、どんぶらこ。

▶ ブラウザで遊ぶ（無料）インストールなし。リンクを開くとすぐ始まります。
  • 遊べる所スマホ（縦画面）・パソコン
  • 1回の長さ約2分
  • 公開日2026年10月25日
  • 料金無料（広告あり）

どんなゲーム？

桃になって川を流れる3Dライドゲームです。山おくの谷川から、おばあさんが洗濯をしている里の洗濯場まで、約3kmの川を一気に下ります。指で左右によけて、上にはじいてジャンプ。ウォータースライダーのような下り坂や千本鳥居では時速150kmをこえ、最後の大滝を飛ぶと里の上空へ。洗濯物が全部洗い終わる前に、おばあさんのたらいへ飛びこめたらゴールです。記録は「歴代」と「今日」のトップ3が、リアルタイムでみんなの画面に出ます。

遊び方

  1. 「どんぶらこ！」を押すと、3・2・1で川を流れはじめます。
  2. 指を左右にスライドすると、桃が横に動きます。パソコンでは ← → キー（A・D）か、マウスのドラッグです。
  3. 画面を上にはじくとジャンプします。パソコンではスペースキー（↑・W）です。
  4. 画面の上の洗濯物は、12秒に1枚ずつ洗い終わっていきます。全部終わる（120秒）前に、おばあさんのところへ。
  5. 最後は、桃の前に出る白い輪が緑になった時にジャンプすると、洗濯たらいに飛びこめます。

ルール

  • 岩・流木・犬・猿が投げる柿・キジにぶつかると、くるくる回って時間をロスします。
  • 滝は、ふちでジャンプしないと滝つぼに落ちて、ぐるぐる回ってしまいます。
  • たらいを外すと、少し上流までもどされます。
  • 記録は「洗濯が終わる何秒前に、たらいに飛びこめたか」です。間に合わなかった回は記録になりません。
  • 「歴代」と「今日」のトップ3に入ると、名前がランキングにのります（1人1枠。自分の記録をこえた時だけ書きかわります）。

うまくなるコツ

  • 白い矢印の流れに乗ると約1.4倍、きびだんごを取ると3秒間 約1.5倍の速さになります。ぶつからないことより、速い所を通ることが近道です。
  • 滝は、ふちの少し手前でジャンプ。「大ジャンプ！」が決まると、しばらくスピードアップします。
  • 猿の柿は、水面の赤い輪から外へ。キジは、影がうろうろしている間は待って、赤くなった瞬間に横へにげます。
  • 犬は、泳いでいく先を読んでうしろを通るか、ジャンプでとびこえます。
  • 川をふさぐ長い流木はジャンプで。短い流木は、よけてもジャンプしてもOKです。

見どころ

  • ウォータースライダーのような下り坂。カメラが坂を見下ろし、どんどん加速します。時速150kmをこえると「爆速！」。
  • 朱色の鳥居がずらっと並ぶ「千本鳥居」を、障害物なしで一気にかけぬける区間。
  • 波のこぶでは、桃がザブンザブンとはねます。
  • 最後の大滝を飛ぶと、里の上空を飛んで、おばあさんの家が見えてきます。

作者のひとこと

はじめは、川をのんびり流れる時速40kmくらいのゲームでした。遊んでみると物足りず、「ライドなんだから、大げさなくらいでいい」と、速さを4倍近くまで上げています。そのぶんコースも長くして、1回は約2分のまま。カーブや下り坂、千本鳥居も足しました。時間はわざときびしめにしてあるので、白い流れ・きびだんご・滝のジャンプを使いこなして、ランキングのトップ3をねらってみてください。
