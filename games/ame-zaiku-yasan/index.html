飴細工やさん

飴が固まる前に、ハサミで切って、つまんで伸ばせ。

どんなゲーム？

棒の先についた白い飴を、和ばさみで切って、つまんで伸ばして、動物の形にする「飴細工」のゲームです。ハサミで飴をなぞると切りこみが入って出っぱりができ、その出っぱりをつまんで引っぱると、耳やしっぽ、ひれになります。

飴は時間がたつと冷えて硬くなり、だんだん伸びにくくなります。約1分で固まったら形づくりは終わりで、そのあと筆で色をぬり、目をつけて仕上げます。

「屋台をひらく」では、夜市の屋台に子どもが5人やってきて、ひよこ・うさぎ・ねこ・金魚・りゅうを順番に注文します。見本とくらべて形・色・目の100点満点で採点され、点数に合わせて子どもが喜んだり、がっかりしたりします。5人の合計点（500点満点）で称号が決まります。

「じゆうに作る」では、お題も採点もなしで好きな形を作れます。完成したら題名をつけると、わら束に飾った写真になり、画像の保存やXへの投稿ができます。

遊び方

  1. タイトルで「屋台をひらく」を選ぶと、1人目のお客さんが注文します。見本を見てから「つくる！」を押します。
  2. 「切る」を選んで、飴の上を指（パソコンはマウス）でシュッとなぞると、なぞった向きに切れて出っぱりができます。出っぱりは、見ている方に向かって平たく広がります。
  3. 「のばす」を選んで、出っぱりをつまんで引っぱると長く伸びます。体の部分をつまむと、体ごと引っぱって形を変えられます。
  4. 飴の外をなぞると、棒ごと飴を回せます。スマホは2本指で回したり、広げて大きくしたりもできます。パソコンはドラッグか←→キーで回し、ホイールで大きさを変えます。
  5. 飴が固まるか「色ぬりへ」を押すと、色ぬりになります。下の色を選んで筆でなぞるとぬれます。「目」を選んでタップすると目がつきます。「太い筆」を押すと細い筆に変わります。
  6. 「できた！」を押すと、お客さんにわたして採点されます。

ルール

  • 飴は約1分で95℃から55℃まで冷えて固まります。冷えるほど、つまんで伸ばせる量が少なくなり、固まったあとは切ることも伸ばすこともできません。
  • 採点は、形60点・色25点・目15点の100点満点です。形は、見本との輪郭の近さと、耳やくちばしなどの出っぱりの根元と先の位置でくらべます。色は見本と同じ色の部分の多さ、目は2つの目の位置で決まります。目が多すぎると減点です。
  • 飴は棒ごと回せるので、どの向きに作っても、いちばん見本に合う向きで採点されます。
  • 屋台は5人で閉店です。合計点で「飴細工名人」「一人前の飴細工師」などの称号がつき、自己ベストが記録されます。

うまくなるコツ

  • 飴がやわらかいうちに、切ったり伸ばしたりする作業を全部すませましょう。色ぬりには時間制限がありません。
  • うさぎの耳のような長いパーツは、まず短く切ってから、出っぱりの先をつまんで引っぱると作りやすいです。
  • 切る前に、出っぱりを広げたい面がこちらを向くように飴を回しておくと、耳やひれが平たくきれいに広がります。金魚のしっぽは横から見ながら切るのがコツです。
  • 体を広くぬる時は太い筆、細いところは細い筆が便利です。まちがえたら「けす」でぬると白にもどり、「もどす」で1つ前にもどせます。
  • 見本は右上でゆっくり回っています。横や後ろの形もときどき見ておきましょう。

作っていて変えたところ

採点は、はじめ見本と前と横から見た輪郭をくらべるだけでした。ところが、ひよこはほとんど丸いので、くちばしや羽を作っても点がほとんど変わりませんでした。そこで、耳やくちばしなどの出っぱりが、見本と同じ場所から同じ方向へ出ているかもくらべるようにしました。

りゅうの見本は、最初は首を上に長く伸ばした形にしたら、洋なしのような形になってしまいました。口先を前へ伸ばした頭の形に作り直して、つの・ひげ・背中のとげ・しっぽをつけています。

体を広く色ぬりする時、飴のふちの少し外から筆をおろすと、飴が回ってしまってぬれませんでした。今は、ふちの近くから筆をおろした時は、そのまま色をぬれるようにしています。
