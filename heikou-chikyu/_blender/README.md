# 並行地球：Blender の場面づくり

`scene.py` は、計算データ（スタジオの「Blender用 JSON」）から、ある星・ある年・ある島の入り江の景色を組み立てて、Cycles で描きます。

- 地形・海・木・岩・家・舟・空は、すべてこのスクリプトが作ります。外部の素材（画像・モデル・HDRI）は使わないので、利用条件の確認は不要で、どの環境でも同じ景色になります。
- 同じ引数なら同じ景色です（乱数の種は `--seed`、既定は7）。
- このフォルダは名前が `_` で始まるので、サイト（GitHub Pages）には公開されません。

## 使い方

1. 計算データを用意します。スタジオで条件を選んで「Blender用 JSON」を押すか、コマンドで書き出します。

   ```bash
   node heikou-chikyu/studio/_dev/export-blender.js data.json '{"policy":"demand","storm":true}'
   ```

2. Blender で描きます（Mac の例。`--gpu` で Metal を使う）。

   ```bash
   /Applications/Blender.app/Contents/MacOS/Blender -b -P heikou-chikyu/_blender/scene.py -- \
     --data data.json --planet reference --year 24 --island D --out d-y24.png --gpu --blend d-y24.blend
   ```

   Blender 本体がない環境では、Python の `bpy` パッケージ（Blender 5.0）でも動きます：`python scene.py -- --data ...`

3. 細かく直したいときは、`--blend` で保存した .blend を Blender で開きます。

| 引数 | 意味 | 既定 |
|---|---|---|
| `--data` | 計算データ（Blender用 JSON）。なければ手つかずの状態 | なし |
| `--planet` / `--year` / `--island` | どの星・何年目・どの島か | reference / 0 / D |
| `--out` | 描いた画像。`--anim` のときは連番画像の頭（`f_` → `f_0001.png`…） | heikou-scene.png |
| `--res` / `--samples` | 解像度と、1画素あたりの試行回数 | 1920x1080 / 256 |
| `--preview` | 960×540・48回で速く描く（構図や色の確認用） | なし |
| `--camera` | `drone`（入り江の上空16m）か `boat`（水面から2.4m） | drone |
| `--anim` `--seconds` `--fps` | 沖から入り江へ近づくカメラ移動を描く | 12秒・24コマ |
| `--sun-elevation` / `--sun-azimuth` | 太陽の高さと方位（北0・東回り） | 16° / -130°（南西） |
| `--gpu` | GPU で描く（Metal・OptiX・CUDA・HIP の順に探す） | CPU |
| `--border` | 画面の一部だけ描く（左,下,右,上を0〜1で） | なし |
| `--blend` | 編集できる .blend も保存する | なし |

連番画像から動画を作る例：`ffmpeg -framerate 24 -i f_%04d.png -c:v libx264 -pix_fmt yuv420p -crf 18 out.mp4`

## 計算データ → 景色の対応（仮置き）

生物量と画面上の本数は別の量なので、そのまま比例させずに次の規則で対応させています。どれも仮置きで、見せ方に合わせて変えてかまいません。

| 計算データ（その島・その年） | 景色 |
|---|---|
| 森の指数 F（開始時を1） | 木の本数は F^0.75 の割合。集落から行きやすい所（近く・低い所）ほど先に切られ、境目はぼかす。残る木の大きさは ×(0.72＋0.28×本数の割合)。切り跡の約14％には若木が育ち、残りの切り跡の約35％に切り株が残る |
| 人口 | 家の数＝人口÷6.5（3〜60軒） |
| 船（木・軽殻石） | 桟橋の沖に停泊する大きな船。軽殻石の船は白い船体。小さな丸木舟5艘は景色の一部として常に置く |
| 藻類の指数 | 水の色（多いほど少し緑寄り） |
| 潮麦の指数（生物の星） | 浅瀬（深さ0.3〜2.5m）の群生の量 |
| 嵐の強さ | 空の霞と雲の量、日差しの弱さ |

小魚・捕食者・分解者・栄養は、水面の上からは見えないので、まだ景色に対応させていません（水中のカットを作るときの課題）。

## 地形と構図

- 島は「湾の島（D）」を想定した入り江。中心 (0, 340)、海岸までおよそ 210〜385m、山の高さは最大70m前後。x は東、y は北、z は高さ（m）、海面は z=0。
- 浜の後ろに低くなだらかな平地の帯があり、そこから森の山へ上がる。36°より急な所は「崩れ落ち」（熱侵食）の処理でならし、不自然な壁を残さない。
- 集落は浜沿いの平地（中心 5, 160）に東西に長く並ぶ。家は傾き13°以下の所に、互いに9.5m以上離して置き、家のまわり8mには木を生やさない。桟橋、丸木舟、手前右の小さな岩礁（57, 36）がある。
- 海は深さ60mの水の塊で、深さに応じて赤い光から先に吸収される（浅瀬は砂が透けた青緑、深い所は紺）。水面は影を落とさない設定にして、海底に日が届くようにしている。

## 限界

- 砕ける波としぶき、雲の立体、煙、人や動物は未実装。
- 木・家・舟は手続き的に作った簡易なモデル。遠景〜中景向けで、近寄るカットには作り込んだモデルが要る。
- 実写の空・質感（HDRI やテクスチャ）は、この作業環境から素材サイトにつながらなかったため使っていない。使うときは入手元と利用条件を記録する。
