# 並行地球 第1回「地球の99％が海だったら」：計算（1週間版）

住民の判断は、AIではなく**決めた規則と確率**で動かす（A案）。動画でもそう説明する。
同じ版・同じ地形・同じ試行番号なら、何度実行しても同じ結果になる。

## 使い方

```bash
cd heikou-chikyu/_sim
python3 run.py pilot   # 予備計算：C1・A1・S1・R1 × 1回 × 300年
python3 run.py main    # 本番：8地形 × 5回 × 3,000年（40試行）。4コアで十数分
```

結果は `out/`（リポジトリには入れない）に書く。

- `summary.json`：試行ごとの評価
- `terrains.json`：地形の特徴
- `<地形>-<試行>.pkl.gz`：その試行の記録（年ごとの値、出来事、10年ごとの集団と地域の状態、年齢別の死亡）

必要なもの：Python 3.10 以上と numpy（地図の画像には Pillow）。

## ファイル

| ファイル | 中身 |
|---|---|
| `world.py` | 惑星と8地形。島の形と面積、島の性質、地域分け、島どうしの海の幅、面積の確認 |

## 惑星と陸地

- 地球と同じ大きさの球（半径 6,371km、表面積 5億1,006万km²）。海面は標高 0m。
- 陸地は表面積のちょうど 1％（510万0,645km²）。8地形とも同じ。
- **島の面積の出し方**
  - 島の形は、中心から見た方位ごと（360方位）の半径で持つ。
  - 面積は球面上の式 R²∫(1−cos(r/R))dθ で計算する。
  - 0.05度の格子で数え直して確かめる。許容誤差は ±1％で、実際の差は 0.06％以内。
- 島は重ならないように置く（輪郭どうしを36方位で確かめる）。決めた場所に置けなかった島は、面積を保つために地球のどこかへ離して置き、その数を記録する。

| 地形 | 系統 | 並べ方 |
|---|---|---|
| C1 | 大きな陸地へ集中 | 355万km²の島1つ、中くらいの島5つ、小島90 |
| C2 | 大きな陸地へ集中 | 195万・185万km²の島2つ、中くらいの島4つ、小島70 |
| A1 | 近接した群島 | 半径3,200kmの範囲に520島 |
| A2 | 近接した群島 | 半径1,850kmの群島が3つ（各175島） |
| S1 | 飛び石状の島々 | 90島がひと続き。途中に320・560・900kmの長い海 |
| S2 | 飛び石状の島々 | 中心から3本に枝分かれ（各34島）。各枝に300〜650kmの長い海 |
| R1 | 遠く離れた小島 | 2,600の小島が地球全体に散らばる |
| R2 | 遠く離れた小島 | 3〜8島の小さな集まり320が、700km以上離れて散らばる |

- **島の種類：** 大陸性の島、高い火山島、古い火山島、低いサンゴ島。大きさと緯度で、乱数を使って決める。
- **島ごとに持つもの：** 最高標高、気温、降水量、海岸線、浅い海の広さ。
- **資源：** 斧に向く石（サンゴ島では大きな貝の殻）、粘土、銅の鉱石、育てられる芋や果樹、育てられる穀物。
- **地域：** 6,000km²より大きな島は、約4,000km²ごとの地域に分ける。地域ごとに、自然の量、森、大木、畑にできる土地、淡水を持つ。

## 人類の出発点

- 1,000人を200人×5集団として置く。
- **置き方（どの地形でも同じ規則）：**
  1. 暮らしやすさ（採集と漁で養える人数と、道具なしで得られる水の少ない方）が最も高い地域を中心にする。
  2. 歩くかいかだで行ける範囲の、暮らしやすい地域へ順に置く。
  3. 足りなければ同じ地域に重ねる。
- **年齢構成：** 下の死亡率で人口が年0.2％伸びるときの、安定した形。
- **最初から使えるもの：** 言葉、火、打ち欠いた石器、採集と岸の漁、簡単な住まい、いかだ（約30km）。
- **備蓄：** 3か月分の食べ物、住まい（6人に1軒）、いかだ4つ。
- **知っていること：** 自分の島と、そこから見える島。遠くの地図、ほかの集団の場所、見つけていない資源は知らない。

## 1年の計算

1. **気候と災害**
   - 雨の多さは島ごとにゆらぐ（前の年の7割が残る）。
   - 嵐は緯度8〜30度で起こりやすい。住まい・舟・備蓄・植物・貝が傷み、亡くなる人が増える。
   - 津波はまれ（高い火山島で年0.04％）。
   - はやり病は、付き合いのある人の数と密度で起こりやすくなる。
2. **労働**
   - 大人1人が年250人日働く（10〜14歳は100、60歳以上は80）。
   - 水くみ・薪・道具の手入れを先に引く。
   - 残りの労働を食べ物の取り方（採集・狩り・貝・岸の漁・沖の漁・畑・養魚池）に割り振る。取れ高の限界がそろうように割り振り、必要量（＋備蓄の補充）に届くか、労働を使い切ったところで止める。
   - そのあと住まい・舟・畑を広げる作業。残りが余暇。
3. **自然**
   - 植物・獲物・貝・岸の魚・沖の魚は、それぞれロジスティック式で回復し、取った分だけ減る。
   - 森は畑で減り、大木は舟や倉で減る。どちらもゆっくり戻る。
   - 穀物の畑は土をやせさせる。
4. **生死**
   - 年齢別の死亡率に、食べ物・水・住まい・燃料の不足、嵐、はやり病、津波の分を上乗せする。子どもと高齢者は不足の影響を1.5倍受ける。
   - 出生は、女性の年齢別出生率に、食べ物と水の足り具合を掛ける。
5. **知識**
   - 資源は「存在する → 見つける → 性質を理解する → 加工の技術を得る → 使う」と段階を踏む。
   - 技術は、前提の技術と理解した材料がそろったときだけ、余暇の量に応じて思いつく（困っていることに関わる技術は思いつきやすい）。
   - 思いついたあと、決まった人日の開発を終えて初めて使える。
   - 技術は使うほど上達し、次の場合に衰えて失われることがある：人が少ない、材料がない、教える余暇がない。数の記録があると失われにくい。
   - 付き合いのある集団どうしで、技術・資源の知識・作物が伝わる。
6. **探索と移住**
   - **探検：** 舟があると、困っているほど探検に出る。舟の届く距離の中の、まだ知らない島を見つけることがある。舟が戻らないこともある。何度出ても見つからないと出なくなる。
   - **分かれる：** 集団が大きくなりすぎると、4割が暮らしやすい地域へ分かれる。分かれ目の大きさは、採集の暮らしで400人、芋の畑で1,000人、穀物で3,000人。
   - **移る：** 困窮が続くと、集団ごと移る。
   - 海を渡るときは、距離が舟の届く距離に近いほど遭難しやすい。

技術（18）：網とわな、釣り針、干物・燻製、水をためる器、土器、井戸、磨いた石の斧、丸木舟、浮き木つきの舟、帆、星と波の航法、芋や果樹の栽培、穀物の農耕、養魚池、塩づくり、高床の倉、銅の精錬、数の記録。

## 値の根拠と仮定

| 値 | 使った数字 | 種類 |
|---|---|---|
| 惑星の大きさ・陸地の割合 | 地球と同じ・1％ | 企画の前提 |
| 年齢別の死亡率 | Siler モデル a1=0.422, b1=1.131, a2=0.013, a3=0.000147, b3=0.086（出生時の平均寿命 31.4年） | 根拠あり（Gurven & Kaplan 2007 の狩猟採集民。数値は原典で要確認） |
| 出生率 | 足りているときに人口が年0.2％伸びる値（合計特殊出生率 約4.5）。27歳ごろが最も多い形 | 仮定 |
| 食べる量 | 大人1、子ども0.45〜0.75、高齢者0.85（1人1年分＝約2,000kcal×365日） | 仮定（目安は一般的な必要量） |
| 労働日数 | 大人 年250人日 | 仮定 |
| 自然から持続的にとれる量 | 植物 0.35、獲物 0.12（km²あたり×生産力）、貝 0.8（海岸1kmあたり）、岸の魚 0.6（浅い海1km²あたり） | 仮定（狩猟採集民の人口密度 0.05〜1人/km² 程度になるように） |
| 畑の取れ高 | 芋や果樹 30、穀物 75（1km²あたり・年・人分） | 仮定 |
| 森を切り開く手間 | 1km²に3,000人日（斧があると半分以下） | 仮定 |
| 舟の届く距離 | いかだ30、丸木舟40、浮き木つきの舟160、帆500、星と波の航法1,500km | 仮定 |
| 島が見える距離 | 3.57×(√目の高さ20m＋√島の高さ)km。高い島は雲で＋40km | 根拠あり（見通し距離の式） |
| 嵐の起こりやすさ | 緯度8〜30度で年20％、50度までは8％、その先は5％ | 仮定 |
| 技術を思いつく速さ | 余暇1万人日あたり、難しさ1の技術で年0.06％ | 仮定（3,000年の中で差が出るように調整） |
| 技術が失われやすさ | 大人25人未満で急に失われやすくなる | 仮定（小さな集団で技術が失われる考え方：Henrich 2004 などを参考） |

数値が整っていること（負の量がない、食べ物の収支、労働の使いすぎがない）は毎年確かめ、`summary.json` の「検査」に回数を残す。ただしそれは、現実を再現できているという意味ではない。
