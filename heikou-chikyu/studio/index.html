    計算のしくみと書き出しの形式

    1年の流れ

    • 天候（豊作・不作）と嵐が決まる。大嵐は最初の集落の島を直撃し、離れた島ほど弱くなる。
    • 条件を満たした発明が起きる。発明には「知識の累計」と「その分野の経験」（魚をとった量、造った船の数など）の両方が要る。
    • 各集落が、効率のよい手段から順に食料を集める。目標は「必要量 × 方針の倍率」。航路でつながった島どうしは食料を分け合う。
    • 食料と淡水の量で人口が増減する。足りなければ減り、淡水の量を超えても減る。
    • 船は寿命や嵐で失われ、木（海晶材の船は加工の燃料）があれば造られる。航路は1本に船2隻が要る。
    • 混み合うか食料が足りない集落から、船で届く空いた島へ移住する。
    • 生態系を2か月ずつ進める。

    生態系

    • 藻類（潮麦の星では潮麦も）が海の栄養で育つ。魚は藻類を食べ、魚の量の上限は藻類で決まる。大型の捕食者は魚を食べる。
    • 死骸や排泄物は分解者が栄養に戻す。外洋からも少しずつ栄養が入る。
    • 森は燃料・船・畑のために切られ、ゆっくり回復する。手つかずの15％を下回ると、回復がさらに遅くなる。
    • 計算を始める前に、人のいない状態で200年進めて生態系を落ち着かせ、その状態を「手つかず（100％）」とする。

    星ごとの違い

    • 潮麦の星：潮麦は浅瀬の広い島の決まった場所にだけ自生する。栽培を覚えると浅瀬を畑にでき、収穫は多いが、藻類の場所と栄養を奪う。食料に占める割合が高いほど、病気が起きやすい。
    • 海晶材の星：岩の島と北の大島から採れる。海晶材の船は長持ちして遠くまで行け、嵐にも強いが、加工に多くの木を燃やす。量には限りがある。

    偶然（種）

    天候・嵐・ひらめき・病気・沈没は「種」と「年」から決まる。引く順番に左右されないので、同じ種なら3つの星で同じ偶然を共有する。違いが出たら、それは星の条件から生まれた違い。

    Blender用 JSON の形式

    • islands：島の id・名前・地図上の位置（x 0〜100、y 0〜60）と、土地・淡水・浅瀬・鉱石の量（0〜1。北の大島の土地だけ1.4）。
    • planets[].years[]：年ごとの pop（人口）・ships・routes（つながっている島の id の組）と、islands（島 id ごとの値）。
    • 島ごとの値：pop、forest・fish・predators・algae・nutrients・decomposers（手つかずを1とした比）、tideField（浅瀬に占める潮麦畑の割合）、farmland（土地に占める畑の割合）。
    • 例：forest を木の本数や林冠の密度に、pop を家の数に対応させると、同じカメラ位置から年ごとの変化を撮れる。
