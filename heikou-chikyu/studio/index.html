    v0.2 との関係

    • 「v0.2と同じ（人口固定）」は、v0.2 の simulation-source.py と同じ規則・同じ順番・同じ乱数で計算します。v0.2 の12試行の記録と、すべての数値・出来事・輸送が一致することを確認しています。
    • 「人口・移住・技術あり」は v0.3 で加えた拡張です。人口固定の計算に、出生と死亡、淡水の上限、島どうしの移住、知識と4つの技術を足しています。係数はすべて仮置きです。

    1年の流れ（共通）

    • 船の寿命と嵐による沈没 → 食料の傷み → 生態系の1年（96段階） → 食料の採取（潮麦 → 小魚など → 陸上の食用植物の固定順） → 伐採・採掘 → 船の建造（1つの島で1年に1隻まで）。
    • 船の輸送枠を使って、足りない島へ近い島から運ぶ（今の食料 → 備蓄 → 木材 → 鉱石 → 軽殻石）。価格・交渉・対立はなく、協力して分け合う。航路の上限は145（帆の改良の後は200）。
    • 食べる。食料消費と傷んだ食料の70％は枯死物として生態系へ戻る。
    • 拡張あり：移住は輸送の前に行い、食べた後に人口が増減し、知識が増えて技術が生まれる。

    生態系

    • 9つの量（栄養・枯死物・分解者・小魚など・捕食者・陸上の食用植物・森・藻類・潮麦）を、共通の抽象的な物質単位で扱います。実測の重量・個体数・種数ではありません。
    • 人類が採り始める前に160年分計算して、量が大きく揺れない状態を作ります。生命の誕生や進化を再現する処理ではありません。
    • 生物の星は潮麦がある状態で準備するので、開始時の藻類や小魚などの量も基準の星と違います。

    拡張（人口・移住・技術）の仮置き

    • 人口：出生は年3.5％（食料が足りないと減る）、死亡は年2.5％。足りない割合に応じて死亡が増え、淡水の上限を超えた分は毎年その25％が減る。
    • 淡水の上限：A 300・B 240・C 230・D 280・E 220人（v0.2 は初期人口分を確保済みとだけ仮定）。
    • 移住：混み合う島や食料が足りなかった島から、航路の範囲内で余裕のある島へ、年に人口の5％まで。1人あたり物資2単位分の輸送枠を使う。
    • 技術：干物と塩漬け／貯水池／帆の改良／畑の拡大。知識の累計と、その分野の経験（採った食料・造った船・陸上植物の収穫）がそろうと生まれる。

    Blender用 JSON の形式

    • islands：島の id・名前・模式図上の位置（x 0〜300、y 0〜280、単位は仮想km）・資源量・浅瀬・嵐へのさらされやすさ・淡水の上限。
    • planets[].years[]：年ごとの食料の充足・嵐の強さ・輸送（transfers）と、島 id ごとの人口・船（木・軽殻石の数）・在庫・残りの鉱床・9つの量の指数（開始時を100）。
    • 生物量と画面上の個体数は別の量です。森の指数が70だから木の本数を7割にする、と単純に対応させず、密度・大きさ・林冠などの見せ方を決めて対応させます。
